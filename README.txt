ASET IKON UNDUH VIDEO

Ikon dibuat agar serasi dengan identitas Unduh Video:
- Latar gradasi ungu-biru
- Simbol panah unduh putih dan biru
- Ikon persegi untuk aplikasi/PWA

File:
- icon-192.png   -> ganti icon-192.png di root GitHub
- icon-512.png   -> ganti icon-512.png di root GitHub
- favicon-32.png dan favicon-48.png -> opsional, untuk favicon browser
- logo-preview.png -> gambar referensi, bukan ikon aplikasi

Cara pasang:
1. Buka repositori shopppit1-tech/Unduh-video.
2. Upload icon-192.png dan icon-512.png untuk mengganti file yang lama.
3. Commit perubahan.
4. Pastikan manifest.json tetap menunjuk ke ./icon-192.png dan ./icon-512.png.
5. Jika ikon lama masih tampil di PWA yang sudah terpasang, hapus shortcut/aplikasi lama lalu pasang ulang, atau bersihkan data situs/cache.
